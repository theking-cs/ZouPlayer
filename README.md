# ZouPlayer v1.1 🚀

**ZouPlayer** is an optimized plugin for **Enigma2** set-top boxes (Vu+, Dreambox, Zgemma, etc.), designed to manage and play IPTV playlists and multimedia content with a smooth and simple interface.

---
